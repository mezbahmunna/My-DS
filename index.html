How to use DreamSpace

Drag to orbit, pinch or scroll to zoom. Tap an object to select it. Use Move, Rotate or Scale, then drag the coloured handles. Edit exact numbers in the Inspector. Everything autosaves in this browser; use Export JSON for a backup file.

Undo / Redo cover add, delete, duplicate, transforms, colour, rename, visibility, clear and settings changes made through those controls.
